# LiveShellunofficial 1.8.0

由 HOMEFTW 维护的非官方分支，基于 [AZiZ（ZiZc3）的 LiveShell Engine](https://github.com/ZiZc3/LiveShell)。项目遵循原有 GPL-3.0 许可证；第三方库说明见 `THIRD_PARTY_NOTICES.md`。

项目与下载：[HOMEFTW/LiveShellunofficial](https://github.com/HOMEFTW/LiveShellunofficial) · [发布版本](https://github.com/HOMEFTW/LiveShellunofficial/releases)

## 升级与使用

1. 升级前先重启 PS5 或 ShellUI，再加载新版 `liveshell.elf`，确保使用新的注入模块。
2. 打开主屏上的 LiveShellunofficial，在“图片”选择静态壁纸。
3. 在独立的“背景音乐”入口选择 MP3，或选择“不播放音乐”。音乐为全局选择，无需与每张图片对应保存。
4. “设置 → 背景音乐”可选单曲循环或列表循环；音乐选择、音量和循环方式均会保存。
5. 返回主屏显示图片后播放音乐。在主机管理窗口内、显示视频或隐藏图片时，音乐会暂停。可使用手机／电脑远程页观察主屏播放状态。
6. “设置 → 界面语言”切换简体中文／English；两个页面共享主机保存的语言设置。
7. “设置 → 关于”显示 1.8.0、维护者、原作者及项目链接。

## 文件存放

内部存储：

```text
/data/LiveShell/
├── video/       MP4 视频
├── pictures/    PNG、JPG、JPEG 图片
└── music/       MP3 背景音乐
```

U 盘使用根目录下的 `liveshell/video`、`liveshell/pictures`、`liveshell/music` 三个文件夹。完整包内附空目录模板。在对应页面上传文件，程序会自动存入相应目录。

旧版直接放在 U 盘 `liveshell` 根目录的 MP4 仍可读取。图片不要放入视频目录，避免与视频缩略图混淆。

## 支持范围

| 类型 | 支持范围 |
|---|---|
| 视频 | MP4，H.264 或 HEVC，最高 4K |
| 图片 | PNG、JPG、JPEG，最大 32 MB，每边不超过 4096 像素 |
| PNG | 8 位、非隔行扫描 |
| JPEG | 8 位 RGB／灰度，基线或渐进式 |
| 音乐 | MP3，单声道／立体声，8–48 kHz，最大 64 MB |

图片保持比例并居中裁切。含图片的壁纸播放列表需使用时间间隔切换，“视频结束时切换”只适用于视频。

音乐在 payload 中解码，PCM 通过本机回环连接交给 SceShellUI 的 MAIN 音频端口输出。界面在接收端成功提交音频后显示“播放中”；连接或原生接口错误会显示相应状态。

## 配置与排查

- `/data/LiveShell/config.txt`：语言及其他设置。
- `/data/LiveShell/music.txt`：全局音乐选择、音量与循环方式。
- `/data/LiveShell/liveshell.log`：运行日志；音乐相关行带有 `music:`。
